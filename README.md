# ESP32_WebGPIO 🚀

ESP32 Web-based GPIO Control Library

## ✨ Features
- Dynamic button generation
- Control multiple GPIO pins
- Static IP support
- Simple and lightweight

## 📦 Installation
Download or clone this repo and place inside:
Documents/Arduino/libraries/ESP32_WebGPIO

```cpp
int pins[] = {2, 4, 5};
